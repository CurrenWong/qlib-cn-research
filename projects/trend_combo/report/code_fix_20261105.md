## 修复 2：`composite.py` —— 没有当日收盘价的票，price_score 置 NaN

**根因**：`build_dataset.py` 的 `close.pct_change()` 默认 `fill_method='pad'`，
停牌/退市股的价格被前向填充成一条平线 → `price_pos_250` 等因子恒取极端值 →
winsorize + z-score 后挤到截面上限 → **20 只买不到的死票并列占满纯价量排名的前 20 名**。

**修法**（`tools/composite.py`）：

```python
if "close" in panel.columns:
    no_px = panel["close"].isna()
    panel.loc[no_px, "price_score"] = np.nan
```

语义上也更对：**没有收盘价 = 当天不可交易，就不该有价量分**。

**效果**：

| | 修复前 | 修复后 |
|---|---|---|
| price_score 最大值 | 0.5694（**20 只并列**） | 0.4342（**1 只独占**） |
| 前 30 名里等于 max 的 | 20 | 1 |
| 10-30 截面上「打到上限的僵尸股」 | 20 / 20 | **0 / 20** |
| 混合分 top20（全池 637）vs 剔僵尸池 | 不相等 | **完全相等** |

## 修复 3：仓位规则 —— 等权 + 单票权重上限 10%

**根因**：旧规则「每只 1 万 + 零头补一手」在高价股上失控：
寒武纪 907 元/股 → 1 手就是 9.07 万，**单票权重冲到 39%**；
90 元的票 → 补一手变 2 手 = 1.8 万 = 7%。

**修法**（`tools/counterfactual_oct.py`，两遍执行 + 迭代到收敛）：

1. **第一遍**：目标金额 = 名义总预算（20 万）/ 只数，手数**向下取整**到 100 股整数倍；
   一手就超过「名义预算 × 10%」的票直接剔除。
2. **第二遍**：按**实际投入**重算单票上限（实际投入 × 10%），超限的按整手裁小，
   裁到 0 则剔除该票；**迭代到收敛** —— 剔除后分母变小、权重会反弹，所以要反复重算。
   等权目标固定在名义预算上，不随裁剪缩小（否则越裁越少）。

**效果**：本轮 7 个组合的单票最大权重全部 ≤ 10%（6.16% ~ 9.96%）。
被剔除的票都有明确记录，例如「一手 90,761 元 > 单票上限 20,000 元」。
