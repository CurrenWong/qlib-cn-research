# 科大讯飞（002230.SZ）· 涨跌归因与结构分析

> 主报告：[`news_attribution/REPORT.md`](news_attribution/REPORT.md)
> 执行计划：[`PLAN.md`](PLAN.md)

## 这是什么

把江淮汽车（600418）那套「事件 → 新闻/公告 → 因果方向 → 事件研究」的流水线套到科大讯飞上，
并额外做了 600418 那边没有的**结构分析**（18 年收益解剖、涨跌停赚钱效应、关键窗口超额对比）。

数据覆盖 **2008-05-12（IPO 首日）~ 2026-10-27，4396 个交易日**，比 600418 的窗口更长。

## 核心结论

1. **18 年年化 16.07%，沪深300 只有 0.27%**，年化超额 +15.8pct；但超额几乎全部来自
   2009–2015（+262.7pct）和 2023（+61.4pct）两段。
2. **2024·9 之后那波 AI 行情只跑出 7.9pct 超额**（基本跟随大盘），2026 年再跑输 10.8pct
   → **AI 标签的边际效应在衰减**。
3. **"利好公告日"经常是下跌日**：2022 年报当日 -9.2%、星火大模型发布会次日 -8.6%、
   1024 开发者节前跌停 -10.0%；业绩/财报类公告 T0 超额 -0.551%。
4. **跌停比涨停更可预测**：跌停次日平均再跌 2.14%、胜率仅 32.1%（n=28）；
   涨停次日 +1.21%、胜率 56.9%，但 20 日后超额归零（+0.14%、胜率 50.0%）。
5. **事后归因 ≠ 事前可知**：有事前证据的事件 T+1 胜率仅 48.4%，全部事件 T+5 胜率 49.0%。
