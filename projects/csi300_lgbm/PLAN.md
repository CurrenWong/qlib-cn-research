# PLAN —— 沪深300 × LightGBM 选股策略（训练 / 回测 / 最新推荐）

项目目录：`projects\csi300_lgbm\`
数据源：`qlib_data\cn_data_2026`（最新 **2026-10-30**，上周五收盘，本项目开工时是周一开盘前）
解释器：`.venv\Scripts\python.exe`（pyqlib 0.9.8 / lightgbm 4.7.0）

---

## 0. 目标

1. 用 LightGBM 在**沪深300** 上训练一个横截面选股模型，回测出可复现的样本外业绩；
2. **严格三分**：训练 / 验证 / 测试，测试集只在最后跑一次，不参与任何选型；
3. 用**最新完整数据**（2026-10-30）给出"现在值得买入的 10 只股票"及理由；
4. 产出 HTML 报告 → PNG，发给用户。

## 1. 关键设计决策

| 项 | 决定 | 理由 |
|---|---|---|
| 股票池 | **时点成分股**（`instruments/csi300.txt` 的 start/end 区间，逐日取当日在池成分） | 用当前 300 只回溯 = 幸存者偏差，AGENTS §5.2 的教训 |
| 最新池 | 成分文件只更新到 **2026-10-27**（数据源 release 2026-10-27），用它作最终推荐池 | 2026-10-28~30 无成分更新，只能用最新已知成分 |
| 特征 | 自建 **31 个价量特征**（动量/反转/波动/均线/量比/RSI/Amihud/Beta/52周位置/ATR…） | cn_data **没有基本面字段**，只有价量；特征全部无量纲、跨股票可比 |
| 标签 | 未来 **5 日**收益 `close_{t+5}/close_t-1`（对齐周度调仓）；同时算 1 日标签做对照 | 周度调仓 → 5 日标签才自洽；1 日标签噪声大 |
| 模型 | LightGBM（LGBMRegressor），早停用验证集 | qlib 环境自带 |
| 基线 | **必须保留**：①沪深300买入持有 ②池内等权 ③MA20 趋势过滤 ④LGBM top-K | AGENTS §5.2：候选池必须保留"干脆别择时"的退路 |
| 调仓 | 周度（每 5 个交易日），选股期在**验证集**上定 | AGENTS §5.4：换手 49 倍是杀手 → 成本必须压住 |
| 成本 | 买入 0.05% / 卖出 0.15%，最低 5 元，账户 100 万 | 与 jac_600418 项目同口径，可比 |
| 涨跌停 | 买入日涨停（ret≥9.8%）跳过 | 顶格买不进，回测不能假装能买 |

## 2. 时间切分（防泄漏的硬约束）

```
2016-01-01 ─────── 2019-12-31 │ 2020-01-01 ─────── 2022-12-31 │ 2023-01-01 ─────── 2026-10-30
        训练 TRAIN (4年)       │   验证 VALID (3年)          │     测试 TEST (3.8年)
                                 ↑ 全部选型只在这里做           ↑ 只在最后跑一次
```

- **训练**：2016-2019，拟合 LightGBM；
- **验证**：2020-2022，选超参、选特征子集、选 top-K、选调仓频率、选阈值；
- **测试**：2023-2026，**只跑一次**；测试期用**年度 walk-forward**（每折用"截至上一年末"的数据重训），
  折内不碰测试年数据；
- 训练标签必须"可知"：预测日 t 的训练样本必须满足 `t + 5 ≤ 预测日`（标签期末 < 预测日）；
- 最终推荐模型：超参用验证集选定的配置，在**标签已知**的全部数据（截至 2026-10-30）上重训，预测 2026-10-30。

## 3. 流水线

| 脚本 | 作用 |
|---|---|
| `tools/build_dataset.py` | qlib 取数 → 面板矩阵 → 31 特征 + 标签 → `data/features.parquet` |
| `tools/train_select.py` | walk-forward 训练 + 验证集选型 → `results/dev_metrics.json`、`results/oos_preds.parquet` |
| `tools/backtest.py` | 组合仿真（成本/涨跌停/停牌）vs 4 个基线 → `results/backtest.json` |
| `tools/rank_latest.py` | 最终模型 → 最新一日 top10 + SHAP 理由 → `results/picks.json` |
| `tools/make_figures.py` | 图表 → `report/img/` |
| `tools/build_report.py` | HTML 报告 → `report/report.html` |
| `tools/check_report.py` | **自检**（泄漏、切分、成本、指标一致性） |
| `render_png.py` | headless Chrome 截图 → `report/report.png` |

## 4. 自检清单（`check_report.py` 必须全过）

1. 训练样本的标签期末 **<** 预测日（逐折检查，无一例外）；
2. 特征只由 t 及之前的数据构成（抽样重算比对）；
3. 训练/验证/测试区间无重叠；
4. 回测扣了成本（成本拖累 > 0，且换手率与成本同号）；
5. 报告里每个数字都能从 `results/*.json` 回溯（数字一致性比对）；
6. 基线都在，且策略没跑赢所有基线也不粉饰。

## 5. 不做的事

- 不做日内、不做杠杆、不做空、不接基本面（数据里没有）；
- 不为"好看"调参：测试集只跑一次，结果差就如实报；
- 不把"预测"说成"保证"：报告里写清目标价是模型输出、样本外统计显著性的实际水平。
