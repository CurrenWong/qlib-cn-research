# 持仓追踪：2026-11-02 开盘建仓 → 连续追踪一个月

> 决策（用户 2026-11-03 拍板）：**A 口径保留**，从 2026-11-02 开盘这 20 只开始连续追踪一个月。
> 本文件是**每日怎么跑**的操作手册。

## 一、每日一条命令

```bat
.venv\Scripts\python.exe projects\csi300_lgbm\tools\track_pnl.py
```

- **手动跑，不注册定时任务**（沿用本项目既有约定：数据更新也是手动一条命令 + 自动刷新状态文档）
- 跑一次 ≈ 40~60 秒（21 个接口请求：20 只日线 + 沪深300 + 20 次分红查询）
- **幂等**：同一天重跑只会覆盖那一天的 CSV 行，不会重复累加
- 收盘后（15:00 之后）跑即为当日净值；盘中跑取到的是最新价（腾讯接口实时），行会按当前交易日覆盖

## 二、口径定义（别改，改了就对不上历史行）

| 项 | 定义 |
|---|---|
| 持仓 | 冻结台账 `results/positions_A.json`：**20 只，股数与成本价永不变**（不重新选股、不再平衡） |
| 建仓 | 2026-11-02 **开盘**成交，A 口径：每只约 1 万元，**向上取整到整手**、零头补一手、至少 1 手 |
| 总成本 | **256,525 元**（比 20 万预算多 28%，因为高价股一手就 1.5~2 万） |
| 收益率 | 总资产 ÷ 总成本 − 1；总资产 = **持仓市值 + 累计税后现金分红** |
| 基准 | 沪深300（SH000300），两个起算法都报：**开起**（与建仓同一时点，主口径）/ **收起** |
| 超额 | 组合收益率 − 沪深300（开起） |
| 除权 | 东财 RPT_SHAREBONUS_DET 自动取除权除息日与每 10 股派息；除权日股价下调，**分红另计入现金**，不算亏损 |
| 红利税 | 按持有期差别化：≤1 个月 20%、1 个月~1 年 10%、>1 年 0%（宁波银行 11-05 除权，持 3 天 → 税 20%） |
| 停牌 | 无当日 bar 时沿用最后收盘价，并在 `n_stale` 列标记 |

## 三、产出文件

| 文件 | 内容 |
|---|---|
| `results/positions_A.json` | 冻结台账（20 只、股数、成本价、基准）— **不要手改** |
| `results/track_pnl.csv` | 每日一行：日期 / 市值 / 累计分红 / 总资产 / 收益率 / 基准两种收益 / 超额 / 停牌数 |
| `results/track_positions_latest.csv` | 当日逐只明细：股数 / 成本价 / 现价 / 市值 / 盈亏 / 收益率 / 权重 |
| `results/pnl_monday.json` | 建仓当天的完整测算（A/B/C 三口径 + 对账） |

## 五、月末决策点：跟不跟策略换仓？

策略的规则是 **top20 + 月度调仓 + 2× 缓冲带**：现有持仓只要还在 top40 里就不动，掉出 top40 才换掉。
到 11-30 会产生新的一份 top20。两条路：

- **A. 不换（继续静态跟踪）**：优点是这个月是干净的一次"样本外观察"，能回答"名单躺一个月会怎样"；
  缺点是偏离了策略本身，回测结论（月度换 + 缓冲带的收益）用不上。
- **B. 跟策略换**：优点是可执行；缺点是**换仓会把 11 月的观察污染**（变成"换过手的组合"），且换仓有成本（回测口径约 2.03%/年）。

**建议：先跑完 12-01 再定**。如果中间已经出现明显跟踪误差（模型信号 vs 实际持仓偏离过大），可以随时中止。

### 若决定跟策略换，需要的步骤

```bat
:: 1) 把 qlib 本地行情补到 11-30（注意 --until 排除当天未收盘的 bar）
.venv\Scripts\python.exe tools\append_latest_bars.py ^
  --dir qlib_data\cn_data_2026 ^
  --symbols-file projects\csi300_lgbm\universe_latest.txt --until 2026-11-30

:: 2) 用冻结的超参跑最新排名 → results/picks_K20.json
cd /d projects\csi300_lgbm
.venv\Scripts\python.exe tools\rank_latest.py 20

:: 3) 还原真实价 → results/picks_K20_price.json
::    ⚠ real_price.py 里日期是硬编码的 "2026-10-30"（start/end 与 as_of），月末跑前必须改成 2026-11-30
.venv\Scripts\python.exe tools\real_price.py

:: 4) 对比当前持仓：谁掉出 top40 → 要换掉的名单；谁是新进 top20 → 要买进的名单
:: 5) 按 A 口径算换仓金额与成本（买 0.05% / 卖 0.15%，每笔最低 5 元）
:: 6) 更新 positions_A.json（股数、成本价、分红事件），重跑 track_pnl.py 生成新起点
```

## 六、每天看什么（三条就够）

1. **组合 vs 沪深300 超额**（`track_pnl.csv` 的 `excess_pct`）——这是策略有没有用的唯一指标

   这正是上一版「10 只太集中」教训在 20 只版本上的延续
