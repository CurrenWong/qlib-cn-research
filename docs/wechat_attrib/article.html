财报出来就跌？两家公司、1347 次大波动，我用同一套方法去找“新闻解释了谁”

有人问：一只股票突然涨 10%，是不是有什么消息？

我用同一套方法，把江淮汽车（600418）和科大讯飞（002230）从 2001 年到今天的所有“明显波动”翻了一遍， 共 1347 个事件、4665 条公告、603 条新闻，逐条去问：那天之前，到底有没有能对上的消息？

把它当研究起点，不是买入清单。

先放三个现场。

  • 2023-08-16，科大讯飞“星火认知大模型升级发布会”提示性公告的次日，股价 -8.6%。
  • 2023-04-21，科大讯飞 2022 年报披露的当天，股价 -9.2%。
  • 2020-11-26，江淮汽车发布“关于江淮大众合资合作事项的进展公告”，股价 -8.15%。 而同一个题材：2020-11-04 发“进展公告”涨 +9.95%，2020-12-03 “交割完成”涨 +10.02%。

同一家公司，同一条主线，三次公告，三种完全相反的价格反应。消息面到底在干什么？

• • •

一、我真正想回答的三个问题
  1. 每次大涨大跌，前面到底有没有“消息”？ 如果有，能找到的比例是多少？
  2. 找到消息之后，它还能预测后面的走势吗？ 换句话说，“事后解释”是不是被误当成了“事前信号”。
  3. 这套方法跨行业、跨年代还成立吗？ 汽车股和 AI 股、2005 年和 2026 年，结论会一样吗？

选这两个标的不是随机的：江淮汽车是沪市主板的传统周期制造企业，2001 年就在数据里；科大讯飞 2008 年上市， 是深市主板的 AI 叙事代表，行业、年代、市值风格都不一样。

• • •

二、方法：把“为什么涨了”拆成四步

新闻归因流水线：事件识别 → 数据校验 → 候选池 → 因果判定

第 ① 步：什么算“事件”？

不要主观挑日子，用三个客观口径取并集，全部相对沪深300 计算：

  • L1 绝对涨跌 ≥ 5% —— 明显涨跌；
  • L2 相对沪深300 超额 ≥ 4% —— 剔除大盘 beta 之后的个股特异性波动；
  • L3 涨跌停（|涨跌| ≥ 9.5%） —— 情绪极值。

江淮命中 773 次，科大讯飞 574 次，合计 1347 次。

第 ② 步：数据校验——这一步救了我两次

qlib 本地数据是前复权价，除权日会凭空造出“假崩盘”。江淮就有 2005-12-14 这种： qlib 显示 -6.18%，而新浪前复权显示当天是 +7.32%——真实行情完全相反。 所以每次都必须拿第二个行情源（新浪）逐日对账，差异超过 2 个百分点的日子直接剔除。

科大讯飞这次干净得多：4397 个共同交易日，相关系数 0.999738，最大差 0.64pct，0 条假事件。

还有一个更隐蔽的坑：停牌日的伪事件。科大讯飞有 4 天停牌（2008-08-18、2015-07-08~10）， 个股没开盘，但大盘在动，程序就把这些日子记成了“个股特异性波动事件”。 它们的 T+1 根本不存在——早期版本把这种空值当成“亏损”计入胜率分母，把胜率压低了 0.1~1.2 个百分点， 本版已修正。

第 ③ 步：候选池——公告 + 新闻，但要分清时间关系

  • 公告：巨潮资讯全历史（江淮 2309 条、科大讯飞 2356 条），按“披露日 ≤ 事件日”取；
  • 新闻：东财个股新闻（江淮 354 条、科大讯飞 249 条），注意它只能回溯到 2026-04。

第 ④ 步：因果方向判定——这是全篇最关键的设计

收盘之后写的报道、第二天写的复盘，都不是原因，是结果。

所以必须把候选分成“事前证据”（T-1 公告 / T 日公告 / T 盘前新闻 / T-1 新闻 / T 盘中新闻）和 “事后报道”（T 盘后 / T+1）。只有前者参与归因打分，后者单列。

再加一条证据强度排序：标题里点名“江淮/讯飞”的强于列表类点名文章（“融资客控盘比例超一成个股”这种）， 泛行业综述直接降权 40 分。

三、结果一：七成以上的大波动，根本找不到事前证据

分时期的有事前证据率：2001-2019 只有 23.4%/21.5%，2026-04 有新闻源后跳到 94.1%/66.7%

时期 江淮 有证据率 讯飞 有证据率
2001–2019（只有公告） 23.4%（n=433） 21.5%（n=433）
2020–2026（只有公告） 32.4%（n=306） 23.9%（n=138）
2026-04 起（公告 + 新闻） 94.1%（n=34） 66.7%（n=3）
合计 30.1%（773 次中 232 次） 22.3%（574 次中 128 次）

这张表最重要的一行是最后一行。 一旦有了可机读的新闻源（2026-04 之后），江淮的证据率从 30% 跳到 94.1%。

也就是说：前面二十年“找不到理由”，绝大多数不是因为没有原因，而是因为当时没有地方能找到原因。 这是数据可得性问题，不是市场结构问题——很多人在这里得出过“消息面无用”的结论，其实只是数据不够。

（科大讯飞 2026-04 之后只有 3 个事件，66.7% 这个数样本太小；但逻辑同上：2026 年它压根没怎么动。）

增持、回购、业绩预增——这些在散户眼里最"硬"的利好，落地当天股价往往在跌 （①⑦⑧）。而大众合资那条线，同一个题材三次公告三次不同结果（②③涨停、④跌停、⑤又涨停）。

这不是段子，是机制：市场的定价不是由“消息好不好”决定，而是由“消息相对预期的位置”决定。 业绩预告超预期就涨停，等年报出来发现细节没那么好就跌；发布会之前涨完了，发布会当天就是出货窗口。

量化上更清楚：科大讯飞“业绩/财报”类公告的当日（T0）超额是 -0.551%（n=187）—— 公告密集的年份，往往是失望密集的年份。

五、结果三：公告类别不是 alpha，同一类别跨标的还常常符号相反

11 类公告的次日（T+1）超额收益：两个标的符号频繁相反，胜率都在 50% 附近

公告类别 江淮 n / T1 / 胜率 讯飞 n / T1 / 胜率
分红派息 22 / +0.54% / 63.6% 24 / +1.02% / 62.5%
业绩/财报 205 / -0.24% / 45.4% 187 / +0.27% / 51.3%
股东行为 468 / -0.00% / 43.6% 363 / +0.24% / 49.0%
资本运作 170 / -0.15% / 37.6% 236 / +0.37% / 47.5%
人事治理 290 / +0.09% / 46.2% 341 / +0.40% / 48.1%
合作/新产品 64 / -0.25% / 43.8% 174 / -0.16% / 40.8%
股权激励 37 / -0.39% / 40.5% 222 / -0.25% / 36.9%
产销数据 217 / +0.14% / 43.8% —

三件事：

  1. 股权激励在两个标的上都是最差的类别（江淮 -0.39%、胜率 40.5%；讯飞 -0.25%、胜率 36.9%，n=222）。 市场把股权激励当“股东摊薄”读，而不是“利好”。
  2. 同一类别在两个标的上符号相反：资本运作江淮 -0.15%、讯飞 +0.37%；业绩/财报江淮 -0.24%、讯飞 +0.27%。 如果这类效应真实存在，它至少应该是跨标的稳定的——它不是。
  3. 分红派息两边都最好（胜率 62.5% / 63.6%），但 n 只有 22~24，样本太小，只能当线索，不能当结论。

结论很硬：公告类别不是能直接用的因子。真要用，也得先在你自己那个标的上做样本外验证。

六、结果四：涨停的动量活不过 20 天，跌停的杀伤力两个标的都成立

涨停次日有 1%~2% 超额，但 20 天后归零；跌停次日继续跌

江淮 600418 讯飞 002230
涨停 T+1 +1.93%（胜率 56.5%，n=92） +1.21%（胜率 56.9%，n=58）
涨停 T+5 +0.05%（胜率 43.5%） +1.22%（胜率 53.4%）
涨停 T+20 +0.06%（胜率 41.3%） +0.14%（胜率 50.0%）
跌停 T+1 -0.63%（胜率 48.6%，n=35） -2.14%（胜率 32.1%，n=28）
跌停 T+20 -0.46%（胜率 34.3%） +0.19%（胜率 39.3%）
  • 涨停：两个标的次日都多赚 1%~2%，胜率都在 56% 上下——但江淮到 T+5 就基本归零， 讯飞撑到 T+5 还有 +1.22%，到 T+20 也只剩 +0.14%、胜率 50.0%。动量是有保质期的。
  • 跌停：两个标的次日都是负的。讯飞更狠——次日平均再跌 2.14%，七成概率继续跌（胜率 32.1%）。

这个不对称挺有意思：在这两个标的上，“利空落地”比“追涨停”更容易抓到。 跌停是更强的负向信号，而涨停的动量很快会被抹平。

七、结果五：AI 标签的边际效应在衰减

两个标的 18 年归一化走势与全部事件点（对数轴）

科大讯飞 18 年（2008-05 上市起）累计 +1465%，年化 16.07%；同期沪深300 只有 +5.1%，年化 0.27%。 它当然是只好股票。但把时间切开看，超额收益的来源非常集中：

窗口 个股 沪深300 超额
2009-07 ~ 2015-06（牛市 + 重组） +1263.3% +64.8% +262.7pct
2015-06 ~ 2016-01（股灾） -51.1% -44.8% +0.4pct
2016-02 ~ 2019-12（AI 冷板凳） +110.4% +41.2% +69.3pct
2023-01 ~ 2023-12（ChatGPT → 国产大模型） +35.2% -11.7% +61.4pct
2024-01 ~ 2024-09-24（AI 调整） -20.3% -1.0% -18.5pct
2024-09-25 ~ 2025-12（9·24 → DeepSeek → 华为） +38.5% +36.1% +7.9pct
2026-01 ~ 2026-10（回调） -28.9% -14.2% -10.8pct

2023 年 ChatGPT 那一波它跑赢大盘 61 个百分点；2024 年 9 月之后同一批 AI 行情（DeepSeek、华为发布会），它只跑出 7.9 个百分点；2026 年大盘跌 14.2%，它跌 28.9%，再跑输 10.8 个百分点。

同一个标签，第一波是真重估，后面几波只是跟随。AI 叙事的边际效应在衰减——这跟归因方法无关， 是价格本身告诉我们的。

另外注意 2015 股灾那行：超额只有 +0.4pct。系统性下跌里，个股消息一文不值。

八、五条结论
  1. 大部分涨跌没有可归因的公开消息。 1347 次事件里，能找到事前证据的只有 22%~30%， 而且其中大部分是“数据刚好覆盖到”造成的。
  2. “利好出尽”是机制，不是段子。 公告当天涨跌，取决于消息相对预期的位置—— 江淮大众同一条主线三次公告三次不同结果，是最好的例子。
  3. 公告类别不是 alpha。 同一类别在两个标的上符号相反，胜率全部落在 45%~52%， 唯一两边都好看的“分红派息”样本量只有 20 出头。
  4. 涨停动量短命，跌停的负向延续更持久。 两个标的上涨停 T+20 超额都归零， 跌停次日继续跌的胜率科大讯飞只有 32.1%。
  5. 事后归因 ≠ 事前可知。 有“事前证据”的事件，次日超额胜率江淮 46.2%、讯飞 49.6%—— 都不过 50%。新闻解释“为什么会这样”，不解释“接下来会怎样”。

九、这套方法的边界（必须说清楚）
  1. 新闻只回溯到 2026-04。早期事件的“无事前证据”是数据缺口，不是事实； 江淮在有新闻源后证据率跳到 94.1%，就是这个道理。
  2. 公告只有日期，没有精确披露时刻。收盘后披露的公告会被算成“当日证据”，实际应归次日 → 少数事件被高估为“有事前证据”。
  3. 命中正文 ≠ 关于这家公司。科大讯飞有一条 -6.1% 的事件，归因到一篇行业分析文章—— 原因是那篇文章把讯飞当对比对象提了一句，不是讲讯飞。机制上仍会有漏网。
  4. 没有做多重检验校正。11 个类别 × 多个窗口 × 两个标的，n 从 4 到 468 不等， 小样本类别出现漂亮数字是常事。
  5. 本文不是策略。我没做样本外回测，没算交易成本，没谈仓位。 本文回答的只是“新闻解释了多少、能不能预测”。

• • •

一句话总结：新闻能告诉你昨天发生了什么，但昨天的故事，明天的价格不认账。
